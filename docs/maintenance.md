# 已知问题与后续计划

## ForeverChatInput

- **输入法按钮待游戏确认**。在中文客户端用回车打开已移出的输入框，确认右侧不显示「中／英」按钮，键盘中英文切换和候选词照常。分别测试 `/fci ime show`、`/fci ime hide` 与 `/fci reset`，检查重载、切换聊天标签和恢复原位后的按钮显示与点击行为。
- **解锁模式待游戏确认**。脱战后用 `/unlock` 拖动「聊天输入框」，点「保存并退出」后按回车确认位置。重新打开解锁模式，拖动后不保存退出，确认此前保存的位置保留。分别用 `/fci` 和解锁模式移动，核对两个入口读到同一位置。用 `/fci reset` 恢复，再检查下一次打开解锁模式时的预览位置。
- **位置待游戏确认**。用 `/fci` 拖动预览并保存，再测试取消、重复打开预览和 `/fci reset`。按回车检查新位置，分别用 Enter 发送与 Esc 取消，切换聊天标签后再打开输入框。重载界面或改变游戏窗口大小后，确认输入框仍在屏幕可见范围，聊天窗口位置保持原样。切换角色检查位置各自保存。
- **外观待游戏确认**。分别使用原生聊天及 EllesmereUIChat 各样式，确认移出的输入框背景、边框、字体和光标。切换 WoW Forever 样式的「纤细」「纤细纹理」和「重青铜色」边框，检查对齐与填色。移动输入框或恢复原位后，核对聊天窗口边框与装饰。
- **兼容性待游戏确认**。与 ForeverChatTab 并用时测试 Tab、Shift+Tab 和命令补全，再检查中文输入法、普通密语、临时弹出的密语窗口和物品链接。进副本或 PvP 后确认发言仍能正常发送。
- **更新后复查**。客户端或 EllesmereUIChat 更新时，复查切换布局、进出战斗和应用新样式是否会覆盖已保存的输入框位置。

## ForeverChatTab

- **输入框短名待游戏确认**。用 Tab 正向与 Shift+Tab 反向切到带地区后缀的公共频道、长中文名称和混合文字的频道，确认编号与短名、悬停全名及草稿位置。用 `/fct` 设置短名和恢复自动，重载界面或变更编号后检查保存结果。分别使用原生聊天、EllesmereUIChat 及 ForeverChatInput 移出的输入框。
- **频道选择待游戏确认**。用 `/fct` 预选小队、团队、副本和公会，分别在独行、组队、进团、进副本以及退队后检查可用频道。取消勾选已加入的编号频道，再关闭自动纳入并手动选择，核对 Tab 和 Shift+Tab 的轮换结果。
- **自定义频道待游戏确认**。在设置中加入一个已知频道，核对客户端成功加入后自动勾选。退出后重新加入、切换频道编号及重载界面，检查原选择是否保留。游戏内验证加入被拒绝时的反馈。
- **兼容性核对**。与 RurutiaSuite、EllesmereUIChat 并用时，确认聊天条按钮仍可以直接选频道，轮换保留草稿。核对密语和以 `/` 开头的命令仍使用原生 Tab 行为。用 `/fct off` 核对停用及重载后的状态，再用 `/fct on` 确认保留频道选择。
